# Golden `.slop` files

One file per format version, opened by the tests to check that old documents still open
identically. They are dedicated to the public domain under
[CC0 1.0](../../../../../LICENSES/CC0-1.0.txt), so that other implementations of the format
([docs/file-format.md](../../../../../docs/file-format.md), under CC BY 4.0) can test against
them.
